STACK: Python / FastAPI

PROJECT: Contact Landing Page API

DESCRIPTION:
An API for a company landing page. Visitors can submit project inquiries through a contact form. The submitted requests are stored in the database and can be managed by administrators.

FEATURES:

CONTACT REQUESTS:
- create a contact request
- view all contact requests
- view contact request details


DATA MODELS:

ContactRequest:
- name: string
- email: string
- location: string
- budget: string
- subject: string
- message: string
