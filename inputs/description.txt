STACK: Python / FastAPI systems

PROJECT: Medical Clinic Platform API

DESCRIPTION: An API for a medical clinic website. Visitors can explore the clinic's services, browse the list of doctors and view their profiles, read medical blog articles, subscribe to the newsletter, and submit a consultation request.

FEATURES:

SERVICES:
- create a service
- view all services
- view service details

DOCTORS:
- create a doctor
- view all doctors
- view doctor details

BLOG:
- create a blog post
- view all blog posts
- view blog post details

CONSULTATION:
- create a consultation request (submit form)
- view all consultation requests

NEWSLETTER:
- subscribe with email
- view all subscribers

DATA MODELS:

Service:
- name: string
- image_url: string
- description: string

Doctor:
- name: string
- image_url: string
- specialty: string
- occupation: string
- biography: string
- experience: string
- certificates: string
- skills: string
- location: string
- phone: string
- email: string
- awards: string
- hours: string

Blog:
- title: string
- image_url: string

- content: string
- author_name: string
- author_image_url: string

Consultation:
- name: string
- email: string
- phone: string
- departement: string
- time: string
- message: string

Newsletter:
- email: string
